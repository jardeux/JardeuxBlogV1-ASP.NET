## 🚀 Proje Hakkında

**Jardeux Blog V1**, ASP.NET Core MVC ile geliştirilmiş bir blog platformudur. Kullanıcılar blog yazıları okuyabilir, yorum yapabilir, içerikleri görüntüleyebilir ve etkileşimde bulunabilir. Modern tasarım, güçlü Entity Framework altyapısı ve kolay yönetim paneliyle öne çıkar.

## ✨ Özellikler

- 📝 Blog yazısı oluşturma ve düzenleme
- 💬 Yorum yapma ve yorum yönetimi
- 📊 Blog istatistikleri (ViewCount & CommentCount)
- 🖼️ Gerçek görsellerle desteklenmiş içerikler
- 🎯 Katmanlı mimari (MVC + Repository + Unit of Work)
- ⚡ TempData destekli bildirim sistemi

## 🧰 Kullanılan Teknolojiler

- ASP.NET Core MVC
- Entity Framework Core (Code First)
- SQL Server
- Bootstrap 5
- LINQ
- TempData, ViewBag, PartialView
- HTML5, CSS3, JavaScript
